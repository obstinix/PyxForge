PyxForge portable (Windows x64)
================================

Run
---
Unzip this folder anywhere (a USB drive, Downloads, a folder with spaces in its name) and run
PyxForge.exe. Nothing is installed and no administrator rights are needed. Windows 10 version
1809 or later is required, with an OpenGL 2.1 graphics driver.

  PyxForge.exe   the desktop app (no console window)
  pyxforge.com   the same program for a terminal:  pyxforge.com doctor
  nvim\          Neovim 0.12.6, the official build, used by the editor
  examples\      a 512-byte boot sector project to try: open examples\boot-sector

To open a project: run  PyxForge.exe "C:\path\to\project", drag a folder onto PyxForge.exe,
or use File: Open Folder in New Window... in the command palette (Ctrl+Shift+P).

Settings
--------
This folder holds only the program. Settings, caches and the editor's data are kept in your
Windows profile, as for an installed PyxForge, and are shared with one if you have both:

  %APPDATA%\PyxForge                          settings, open workspaces, tool paths, diagnostic snapshots
  %APPDATA%\fyne\io.github.obstinix.pyxforge  theme and preferences
  %LOCALAPPDATA%\PyxForge                     caches: the editor's configuration, logs, QEMU snapshot overlays
  %LOCALAPPDATA%\pyxforge-data                the editor's plugins, history and language-server log

PyxForge also leaves an empty folder %LOCALAPPDATA%\fyne, and checking Neovim's version leaves
an empty nvim.log in %LOCALAPPDATA%\nvim-data, the folder a separately installed Neovim uses
for its own data; leave that one if you use Neovim. Language servers you have installed may
keep their own caches when the editor starts them.

PyxForge writes nothing into this folder. It writes to your projects only when you save a file
or run a build, and never to an installed PyxForge's program files. To remove every trace,
delete this folder and the four folders listed above.

Tools
-----
Git, QEMU, GDB, NASM, compilers and language servers are not included. Each enables its own
feature, and PyxForge starts and edits without any of them. Tools: Doctor... in the command
palette shows which were found, what each is for and how to install it, and lets you choose an
executable. The full guide is INSTALL.md.

PyxForge makes no network connection on its own and sends no telemetry.
